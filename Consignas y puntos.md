## ✅ Requisitos Mínimos (Obligatorios para aprobar)
### Estructura y Arquitectura
- [ ]  Todo el proceso de compra en un **único documento HTML.**
- [ ] Archivos entregados en formato .ZIP o .RAR.
- [ ]  Arquitectura de directorios clara y prolija.
### Diseño
- [ ]  Diseño presente y visualizado correctamente en navegadores comunes.
- [ ] Interfaz navegable y comprensible.
- [ ] Una o más hojas de estilo CSS.
### Catálogo de Productos
- [ ] Catálogo con filtro por categorías.
- [ ] Mínimo **3 categorías** diferentes.
- [ ] Productos obtenidos de **ARRAY multidimensional o OBJECT**
- [ ] **Mostrar en grilla: Nombre, Descripción, Precio, Imagen miniatura, Categoría.**
### Banner de Ofertas
- [ ] Banner flotante con oferta especial al cambiar categoría.
- [ ] Banner visible durante **10 segundos.**
- [ ] Banner **DEBE DESAPARECER** después.
### Carrito de Compras
- [ ] Área que muestre cantidad de productos y monto total.
- [ ] Al hacer click: mostrar TODOS los productos con subtotal y total.
- [ ] Poder quitar productos de uno en uno.
- [ ] Poder quitar todos los productos comprados.
### Checkout
- [ ] Botón para finalizar selección e ir al checkout.
- [ ] Solicitar datos del cliente: nombre, teléfono, email, lugar y fecha de entrega.
- [ ] Solicitar datos de pago: método de pago, cuotas (si corresponde).
- [ ] Posibilidad de cancelar checkout y volver al carrito.
### Programación
- [ ] Uso de técnicas de **manejo de DOM** (crear/eliminar objetos, alterar CSS).
- [ ] Crear dinámicamente: grilla de productos, detalle, ampliación, carrito, checkout.
- [ ] **NO usar innerHTML** (solo permitido para texto interno sin HTML).
- [ ] Usar funciones nativas del DOM para crear/agregar/eliminar elementos.
### Prohibiciones (Desaprueban automáticamente)
- [ ] **NO usar** alert, prompt, confirm.
- [ ] **NO usar** eventos inline en HTML.
